The `Canvas` component provides an Excalidraw-based canvas for building sketch-style interactive interfaces. It comes pre-configured with sensible defaults for AI applications, including view mode, zen mode, and a minimal UI surface.

<Callout>
  The Canvas component receives Excalidraw elements directly. ReactFlow-specific
  primitives such as [Node](/components/node) and [Edge](/components/edge)
  remain available as separate workflow components.
</Callout>

## Installation

<ElementsInstaller path="canvas" />

## Features

- Pre-configured Excalidraw canvas with AI-optimized defaults
- Accepts Excalidraw elements directly
- Restores element defaults before rendering
- View mode and zen mode enabled by default
- Minimal menu/sidebar/footer defaults
- Customizable background color using CSS variables
- Customizable Excalidraw UIOptions and appState
